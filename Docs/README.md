## Featured Projects

### [🌐 GraphReg](https://github.com/JindalChaitanya/GraphReg)
Enterprise-grade, hybrid Graph + Vector RAG platform engineered specifically for complex regulatory compliance text (e.g., SEBI, RBI circulars).

- **Layout-aware parsing** with IBM Docling to preserve schedules and tables
- **Neural zero-shot entity extraction** with GLiNER for precise legal entities
- **2-hop property graph traversal** alongside top-k semantic vector search
- **Cross-encoder reranking** with ms-marco-MiniLM to ensure context precision
- **React Web UI** providing citation-backed, auditable LLM outputs

**Stack:** `Neo4j` · `Qdrant/Chroma` · `BGE-M3` · `LangChain` · `FastAPI` · `React` · `Docker`

> Flagship capstone project for the CDAC PGCP-AI program.

---

### [✂️ CropVision : Object Detection & Dataset Preparation](https://github.com/JindalChaitanya/CropVision)
Desktop application for large-scale object detection and automated image cropping, built with PyQt6 and YOLOv8.

- ~50% faster crop workflows vs. manual annotation
- Adjustable confidence thresholds and class filtering
- Batch processing with visual bounding-box validation
- Exports individual, page-level, or full-dataset crops

---

### [✍️ QuickDraw : Smart Reference Annotation](https://github.com/JindalChaitanya/QuickDraw)
Semi-automatic image annotation tool built on classical computer vision (no black-box model required for matching).

- SIFT + FLANN feature matching
- HDF5-backed feature database
- Auto-annotation with YOLO export
- Interactive desktop GUI

---

### [🎨 AI Cutout Pro : Background Removal & Object Extraction](https://github.com/JindalChaitanya/AI-Cutout-Pro)
Desktop application combining YOLO detection with AI-powered background removal for clean object extraction.

- YOLO detection + U²-Net segmentation
- ONNX Runtime for fast, portable inference
- Interactive editing and edge deployment

---

### [🛠 Image Processing Toolkit](https://github.com/JindalChaitanya/Image-Processing-Toolkit)
Dataset engineering toolkit for computer vision preprocessing at scale.

- Dataset validation, cleaning, and duplicate detection
- Augmentation and annotation-format conversion
- Batch processing utilities
